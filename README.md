# Sinclair's Secrets - Horror Game

[![GitHub release](https://img.shields.io/github/v/release/miracleman14/Sinclair-Secrets-Game?label=Download)](https://github.com/miracleman14/Sinclair-Secrets-Game/releases/latest)
[![Made with Unity](https://img.shields.io/badge/Made%20with-Unity-57b9d3.svg?style=flat&logo=unity)](https://unity.com)

An intense first-person horror game created using Unity, where the goal is to escape the asylum.

## 🎮 How to Play

### Option 1: Download and Play (Recommended)

1. Go to the [**Releases page**](https://github.com/miracleman14/Sinclair-Secrets-Game/releases/latest)
2. Download the latest `Sinclair-Secrets-Game.zip` file
3. Extract the ZIP file to a folder on your computer
4. Run `Sinclair's Secrets.exe` to start the game
5. Enjoy the horror experience!

### Option 2: Play in Browser (Coming Soon)
A WebGL browser version is planned for future releases, which will allow you to play directly in your web browser without downloading anything.

## 💻 System Requirements

- **OS:** Windows 7 or later
- **Graphics:** DirectX 11 compatible graphics card
- **Memory:** 2GB RAM minimum
- **Storage:** 150MB available space

## 🎯 Game Features

- First-person perspective
- Horror/thriller gameplay
- Atmospheric asylum environment
- Escape-focused objectives

## 🛠️ Built With

- Unity Engine
- C# scripting
